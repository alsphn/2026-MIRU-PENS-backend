# MIRU - Sistem Peminjaman Ruangan (Backend)

Repository ini berisi source code Backend untuk aplikasi **MIRU (Minjam Ruang)**, sebuah sistem peminjaman ruangan kampus yang dikembangkan sebagai tugas PBL 2026.

Project ini dibangun menggunakan **ASP.NET Core Web API** dan database **SQLite**.

## 🚀 Fitur Utama

- **CRUD Peminjaman**: Create, Read, Update, Delete data peminjaman ruangan.
- **Database SQLite**: Ringan dan portable.
- **Swagger UI**: Dokumentasi API interaktif.

## 🛠️ Prasyarat

Pastikan komputer Anda sudah terinstall:

- [.NET SDK 9.0 atau 10.0](https://dotnet.microsoft.com/download)
- Git
